# Version

##  v1.0.0
### Features
#### Search
*A user can search for a work using Korean, English, or Romaja. Multiple words can be entered into the search bar for a closer match.*

- Tokenied: "Korean Food" will search for both "Korean" and "Food".
- Weighted Response: Results sorted based on the closeness of the match.
- Cleaned: If a searched item constains extra spaces or non-alphanumeric characters, we clean it up for you!

#### Sharing
*Sajeon is built to be sharable. Therfore, we are providing an easy way for users to share results. Currently, a user can share the URL directly or click on the share button to copy the URL for that specfic word.*

- Click the Share button on any vocabulary card to copy the URL for that word.
- Click the copy button next to the share button on any card to easily copy the Korean word.
